# Dashboard 2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Vier-bloks interactief dashboard op de volledige Picnic-bestelhistorie; S5 eruit; alleen echte data, afgeleide cijfers expliciet gelabeld.

**Architecture:** `_lib/orders.js` haalt ALLE leveringen op (parallel, gecachet) met `parcels` + `brand`. `_lib/analyze.js` krijgt pure aggregatiefuncties (TDD). `dashboard.js` levert de deterministische blokken; `classify-cat.js` levert async de categorie-indicatie (Haiku). Frontend Dashboard-tab herbouwd.

**Tech Stack:** Node serverless (Vercel), vanilla JS + Chart.js (CDN), @vercel/kv, @anthropic-ai/sdk, node:test.

**Datavorm (bevestigd live):** zie spec `2026-06-08-dashboard-2-design.md`. `Delivery = { id, date(ISO+tz), totalCents, parcels, items:[{productId,name,count,priceCents,brand}] }`.

### Unit B: Pure aggregatiefuncties (TDD)

**Files:** Modify `api/_lib/analyze.js`, `test/analyze.test.js`

Implementeer met TDD (test eerst, dan code). Signaturen + verwacht gedrag:

- [ ] `spendingTimeline(deliveries)` → `{ totalCents, avgOrderCents, byMonth:[{month,totalCents,orderCount,itemCount}], byYear:[{year,totalCents,orderCount}] }`. `itemCount` = som van item.count per maand. Gesorteerd oplopend. Leeg → nullen/lege arrays.
- [ ] `brandShare(deliveries)` → `{ huismerkCents, amerkCents, huismerkPct }` (pct = aandeel huismerk in totale regel-uitgaven; 0 bij leeg).
- [ ] `topBySpend(deliveries, n=10)` → `[{productId,name,spendCents,count}]`, hoogste besteding eerst, max n.
- [ ] `orderTiming(deliveries)` → `{ byWeekday:[7]( ma..zo, telling), byHour:[24], byMonthCount:[{month,orderCount}] }`. Dag/uur uit de **wandklok** van de ISO-string (componenten vóór de tijdzone-offset), zodat het de Nederlandse lokale tijd weergeeft. Weekdag: index 0=maandag.
- [ ] `productFrequency(deliveries)` → `[{productId,name,frequencyPct,timesOrdered,usualQty}]` over ALLE leveringen (aanwezigheid per levering), gesorteerd op frequentie. (Voor "vaste kern".) `usualQty` = meest voorkomende count.
- [ ] `uniqueProductCount(deliveries)` → `number` (distinct productIds).
- [ ] `wrapped(deliveries)` → `{ mostBought:{name,count}|null, mostExpensiveOrderCents, totalOrders, totalParcels }`.
- [ ] `unitsMatching(deliveries, regex)` → `number` (som van counts van producten waarvan de naam matcht; voor superlatieven als "pakken melk/koffie").
- [ ] `categoryShares(products, bucketByProduct, buckets)` → `{ shares:{<bucket>:pct}, freshPct, treatPct }` waar `freshPct`=vers, `treatPct`=snacks+dranken+alcohol. `products:[{productId,spendCents}]`.
- [ ] Exporteer alle nieuwe functies. `npm test` groen. Commit.
